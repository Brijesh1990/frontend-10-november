# instructions for convert figma to html and make responsive all pages using tailwind css

1. open a figma file  https://www.figma.com/design/cxzFswotBmkFDdEo4LEdhi/E-Commerce-App-Design--Community-?node-id=2-740&t=9DiMgZNPOp1HLaWK-0

2. extract all images | fonts | pick colors from figma 

3. convert all things in html 

4. figma to html 

5. convert and make responsive used html | css | tailwind 

## see code samples 

