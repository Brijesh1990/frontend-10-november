# GitHub Definition

GitHub is a web-based platform used for version control and collaboration. It allows developers to store, manage, and track changes to their code repositories. GitHub is built on top of Git, a distributed version control system, and provides a user-friendly interface for managing Git repositories. It supports collaborative development, issue tracking, and project management, making it a popular choice among developers and teams.

## Common Git Commands

1. **git init**: Initializes a new Git repository.
2. **git clone [url]**: Clones a repository into a new directory.
3. **git add [file]**: Stages changes for the next commit.
4. **git commit -m "message"**: Commits the staged changes with a message.
5. **git status**: Displays the state of the working directory and staging area.
6. **git push**: Pushes local changes to a remote repository.
7. **git pull**: Fetches and merges changes from a remote repository.
8. **git branch**: Lists all branches in the repository.
9. **git checkout [branch]**: Switches to a specified branch.
10. **git merge [branch]**: Merges changes from one branch into the current branch.
11. **git log**: Shows the commit history.
12. **git diff**: Shows changes between commits, commit and working tree, etc.
13. **git stash**: Stashes changes in a dirty working directory.
14. **git remote**: Manages set of tracked repositories.
15. **git tag**: Tags specific points in history as important.
