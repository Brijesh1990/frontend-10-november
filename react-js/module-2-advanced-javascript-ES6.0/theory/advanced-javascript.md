# what is oops in javascript ?
  oops stands for object oriented programming structured language
  oops is object oriented language
  oops provides securities 
  oops used class | object | inheritance | encapsulation | abstraction | polymorphism as a features 


## oops features 

   **feature in oops**
   1. class
   2. object
   3. inheritance 
      1. single inheritance
      2. multilevel inheritance
      3. multiple inheritance
   4. polymorphism 
      1. method overloading
      2. method overriding

   5. encapsulation 
   6. abstractions

## javascript partial support oops

  **examples of oops**

  ```
  class A 
{
    constructor(name,age)
    {
      //name and age stored in current object  
      this.name=name;
      this.age=age;
    }
}

var obj=new A("brijesh",35);
console.log(obj);
console.log(obj.name);
console.log(obj.age);
```

## what is arrow function in javascript ?

   **examples of arrow function**
