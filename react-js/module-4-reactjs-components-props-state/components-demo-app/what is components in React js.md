# what is components in React js ?
  1. A components is an small peace of file that can be saved as .js or .jsx i.e called components
  2. A components are reusable 
  3. A components access data parent to child 
  4. A components should be functional 
  5. A components created via App.jsx or App.js whe we create via examples : npx create-react-app appname
  6. A components only created via .jsx (javascript xml) when we used to create app via vite packages 
     examples : DemoApp.jsx or App.jsx
      
# types of components 

  1. function components 
  2. class components 

  **Note : class based components is not support hooks and not able to used in call api via hooks**
